# Analys av försäkringskostnader

Detta projekt undersöker vilka faktorer som har samband med försäkringskostnader (`charges`) genom explorativ dataanalys, visualiseringar och multipel linjär regression. Fokus ligger på att identifiera vilka variabler som bäst förklarar variationen i kostnader mellan kunder, exempelvis ålder, BMI, rökning, hälsotillstånd och tidigare försäkringshistorik.

Projektet använder främst:

- tidyverse
